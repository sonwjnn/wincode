# Web Architecture Profile

## Project configuration

- Framework/rendering: `TanStack Start SPA (Vite + Cloudflare Workers)`
- Source alias: `@/* -> src/*`
- Slice root/name: `src/modules`
- Rendering contexts: `browser`
- Server state: `TanStack Query (via @trpc/tanstack-react-query)`
- Client state: `React Context (auth session, theme)`
- Runtime validation: `Zod`
- UI system: `shadcn/ui (Tailwind CSS v4, components.json)`
- UI generator/registry/destination: `components.json → src/components/ui/`
- Global styles/theme location: `src/index.css` (Tailwind), `next-themes`
- Localization infrastructure: `none`
- Generated-code paths and regeneration commands:
  - `src/routeTree.gen.ts` — regenerated by Vite plugin (auto on dev/build)
- Bootstrap injections: `shared API ← auth token via middleware/auth.ts`
- Error model: `throw unexpected failures`
- Test placement: `co-located`

## Module → Web mapping

Standard frontend terms apply (no re-mapping needed):

| Frontend term | Web mapping                                                                           |
| ------------- | ------------------------------------------------------------------------------------- |
| `ui/`         | React DOM components: shadcn/ui primitives, form layouts, page shells                 |
| `hooks/`      | TanStack Query hooks and form orchestration hooks                                     |
| `context/`    | auth session context and provider state                                               |
| `store/`      | independent client state when Context is not enough                                   |
| `utils/`      | pure feature helpers and rules                                                        |
| `api/`        | Hono API client calls, query options, DTO mapping                                     |
| `app/`        | TanStack Start router, layouts, middleware, root providers                            |
| `shared/`     | domain-neutral web infrastructure: UI primitives, API transport, auth token injection |

## Public entrypoints

- Default: `index.ts` only.

## Verification commands

- Format: `bun x ultracite fix`
- Lint: `bun run check` (root)
- Typecheck: `bun run --cwd apps/web check-types`
- Unit/integration tests: `bun run --cwd apps/web test`
- Build: `bun run --cwd apps/web build`
- Architecture check: `none (manual review)`
- Cycle check: `none (manual review)`

## Approved exceptions

- None.

## Route generation

- Routes directory: `src/routes/`
- Generated tree: `src/routeTree.gen.ts`
- Auto-generated by Vite TanStack Router plugin. No manual regeneration needed.
- Do not edit `routeTree.gen.ts` manually. Excluded from Biome formatting per root `biome.json`.
