## Conclusion

**Verified:** OpenCode's built-in file tools do not expand `~`. The read schema describes `filePath` as absolute but accepts any string; execution preserves an absolute input and resolves every other input beneath the session directory. Thus `~/.claude/settings.json` targets `<session-directory>/~/.claude/settings.json`, not the launching user's home. OpenCode tells the model its working directory, workspace root, and platform, but not its home directory. ([schema and execution](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/opencode/src/tool/read.ts#L23-L35), [resolution](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/opencode/src/tool/read.ts#L218-L250), [environment prompt](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/opencode/src/session/system.ts#L70-L104))

**Verified:** Pi expands a leading `~` locally before resolving against the session `cwd`. It uses `node:os.homedir()` in the Pi process, then sends the absolute result to ordinary local filesystem operations. Pi has no built-in filesystem permission prompt or workspace sandbox; its tools run with the permissions of the user/process that launched it. ([path normalization](https://github.com/earendil-works/pi/blob/a470b121bf683b4c2b9fc0b3a7c807de7e0cfe9c/packages/coding-agent/src/utils/paths.ts#L72-L102), [read execution](https://github.com/earendil-works/pi/blob/a470b121bf683b4c2b9fc0b3a7c807de7e0cfe9c/packages/coding-agent/src/core/tools/read.ts#L219-L266), [security contract](https://github.com/earendil-works/pi/blob/a470b121bf683b4c2b9fc0b3a7c807de7e0cfe9c/packages/coding-agent/docs/security.md#L1-L8))

**Verified locally:** Wincode now expands `~`/`$HOME`, resolves and realpath-canonicalizes the nearest existing ancestor, evaluates and displays that canonical absolute resource, and—after approval—rewrites the actual file-tool input to that same path before execution. ([canonicalizer](https://github.com/sonwjnn/wincode/blob/09f2d13ac87399b9b50d45c1600cf852b4b6bf58/apps/cli/src/modules/permissions/external-directory.ts#L6-L55), [gate and rewrite](https://github.com/sonwjnn/wincode/blob/09f2d13ac87399b9b50d45c1600cf852b4b6bf58/apps/cli/src/modules/tool-gate/tool-gate.ts#L367-L460), [rewritten dispatch](https://github.com/sonwjnn/wincode/blob/09f2d13ac87399b9b50d45c1600cf852b4b6bf58/apps/cli/src/modules/conversations/hooks/tool-dispatch.ts#L210-L236))

## OpenCode trace

1. The AI SDK passes the model argument object through the `tool.execute.before` plugin hook and then to `item.execute`; schema decoding does not add home expansion. ([dispatch](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/opencode/src/session/tools.ts#L50-L113), [decode](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/opencode/src/tool/tool.ts#L93-L137))
2. Read preserves absolute input; otherwise `path.resolve(instance.directory, input)`. `~` is therefore a normal relative path segment. ([source](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/opencode/src/tool/read.ts#L218-L225))
3. Boundary enforcement compares that resolved string to session directory/worktree. `FSUtil.contains` is a lexical `path.relative` check; the external helper does not realpath the target first. ([instance check](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/opencode/src/project/instance-context.ts#L14-L25), [`contains`](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/core/src/fs-util.ts#L270-L273), [external helper](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/opencode/src/tool/external-directory.ts#L15-L47))
4. Workspace-local literal `~` causes no external prompt. If read permission asks, UI obtains `filePath` from original tool input, so it may display literal `~/.claude/settings.json` while execution targets workspace-local `~`. ([permission call](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/opencode/src/tool/read.ts#L238-L250), [UI](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/tui/src/routes/session/permission.tsx#L195-L215))
5. A supplied absolute path outside the project yields `external_directory` metadata containing absolute file/parent paths; after approval the same absolute path reaches stat/read. ([request](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/opencode/src/tool/external-directory.ts#L28-L47), [execution](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/opencode/src/tool/read.ts#L227-L260))
6. Write uses the same no-expansion absolute-or-session-relative rule, then external check, edit approval, and `writeWithDirs`. ([source](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/opencode/src/tool/write.ts#L20-L67))

A tilde inside a **shell command** is different: the selected shell interprets it. Thus `cat ~/.claude/settings.json` uses shell home semantics, while the read tool does not. OpenCode submits shell commands as command strings. ([source](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/opencode/src/tool/shell.ts#L120-L180))

## Pi trace

1. Pi wraps the tool definition as an `AgentTool` and forwards model parameters unchanged to its executor. ([source](https://github.com/earendil-works/pi/blob/a470b121bf683b4c2b9fc0b3a7c807de7e0cfe9c/packages/coding-agent/src/core/tools/tool-definition-wrapper.ts#L4-L21))
2. Read accepts relative or absolute `path` and calls `resolveReadPathAsync(path, cwd)`; write calls `resolveToCwd(path, cwd)`. ([read](https://github.com/earendil-works/pi/blob/a470b121bf683b4c2b9fc0b3a7c807de7e0cfe9c/packages/coding-agent/src/core/tools/read.ts#L21-L26), [read execution](https://github.com/earendil-works/pi/blob/a470b121bf683b4c2b9fc0b3a7c807de7e0cfe9c/packages/coding-agent/src/core/tools/read.ts#L219-L266), [write](https://github.com/earendil-works/pi/blob/a470b121bf683b4c2b9fc0b3a7c807de7e0cfe9c/packages/coding-agent/src/core/tools/write.ts#L193-L231))
3. Shared normalization expands exactly `~`, `~/...`, and Windows `~\\...`, from injected `homeDir` or `os.homedir()`. It does not expand `~otheruser` or literal `$HOME/...`. ([options](https://github.com/earendil-works/pi/blob/a470b121bf683b4c2b9fc0b3a7c807de7e0cfe9c/packages/coding-agent/src/utils/paths.ts#L8-L18), [implementation](https://github.com/earendil-works/pi/blob/a470b121bf683b4c2b9fc0b3a7c807de7e0cfe9c/packages/coding-agent/src/utils/paths.ts#L72-L102))
4. No workspace authorization follows. Default read uses `fs/promises`; injected operations can intentionally route an SDK embedding elsewhere. ([security](https://github.com/earendil-works/pi/blob/a470b121bf683b4c2b9fc0b3a7c807de7e0cfe9c/packages/coding-agent/docs/security.md#L38-L49), [backend contract](https://github.com/earendil-works/pi/blob/a470b121bf683b4c2b9fc0b3a7c807de7e0cfe9c/packages/coding-agent/src/core/tools/read.ts#L52-L76))
5. There is no approval display. Ordinary call rendering keeps a raw `~/...` visibly tilde-prefixed, although execution has resolved it. ([renderer](https://github.com/earendil-works/pi/blob/a470b121bf683b4c2b9fc0b3a7c807de7e0cfe9c/packages/coding-agent/src/core/tools/render-utils.ts#L9-L26), [read renderer](https://github.com/earendil-works/pi/blob/a470b121bf683b4c2b9fc0b3a7c807de7e0cfe9c/packages/coding-agent/src/core/tools/read.ts#L81-L96))

## `/root`, `/home/sandbox`, and macOS homes

Neither agent remaps one **absolute** spelling to another. `/root/...`, `/home/sandbox/...`, and `/Users/alice/...` remain those absolute paths (apart from normal dot-segment resolution); access depends on the executing process's filesystem and permissions. OpenCode additionally asks `external_directory` when outside its project; Pi does not. ([OpenCode](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/opencode/src/tool/read.ts#L218-L250), [Pi](https://github.com/earendil-works/pi/blob/a470b121bf683b4c2b9fc0b3a7c807de7e0cfe9c/packages/coding-agent/src/utils/paths.ts#L97-L102))

For Pi and current Wincode, `~` selects the home inside the process environment: on POSIX, Node uses `$HOME` if defined, otherwise the effective user's OS home entry. Consequently a root-run Linux/container process normally resolves to `/root`, a sandbox with `HOME=/home/sandbox` resolves to `/home/sandbox`, and macOS with `HOME=/Users/alice` resolves to `/Users/alice`. These are conditional examples, not agent hard-codes. ([Node contract](https://nodejs.org/api/os.html#oshomedir), [Pi](https://github.com/earendil-works/pi/blob/a470b121bf683b4c2b9fc0b3a7c807de7e0cfe9c/packages/coding-agent/src/utils/paths.ts#L72-L88), [Wincode](https://github.com/sonwjnn/wincode/blob/09f2d13ac87399b9b50d45c1600cf852b4b6bf58/apps/cli/src/modules/permissions/external-directory.ts#L11-L24))

OpenCode file tools never consult `HOME` for `~`. An explicit `/root/...` means the OpenCode process's `/root/...`; it is not translated to a host macOS `/Users/...` path. ([resolution](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/opencode/src/tool/read.ts#L218-L250), [filesystem backend](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/core/src/fs-util.ts#L1-L12))

## Implications for Wincode nondeterminism

**Verified negative finding:** neither upstream resolver randomly chooses among `/root`, `/home/sandbox`, and `/Users/...`. With the same environment and exact argument, OpenCode deterministically treats `~` as relative; Pi deterministically uses `os.homedir()`. ([OpenCode](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/opencode/src/tool/read.ts#L218-L225), [Pi](https://github.com/earendil-works/pi/blob/a470b121bf683b4c2b9fc0b3a7c807de7e0cfe9c/packages/coding-agent/src/utils/paths.ts#L72-L102))

**Inference:** varying observed spellings most plausibly originate in varying model arguments (literal `~`, a guessed Linux/sandbox home, or a macOS home) or a changing execution environment—not a resolver alternating mappings. This is especially plausible for OpenCode because its read tool requests an absolute path while its environment prompt does not provide a home path. ([schema](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/opencode/src/tool/read.ts#L23-L35), [prompt](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/opencode/src/session/system.ts#L70-L104))

**Current Wincode implication:** one canonical value now crosses authorization and execution. Home expansion and realpath canonicalization precede policy/approval; the approval identity carries the canonical resource; allowed dispatch substitutes that resource into the tool call. This removes ambiguity between approved and executed paths even if the model wrote `~/.claude/settings.json`. ([canonicalizer](https://github.com/sonwjnn/wincode/blob/09f2d13ac87399b9b50d45c1600cf852b4b6bf58/apps/cli/src/modules/permissions/external-directory.ts#L39-L55), [approval/substitution](https://github.com/sonwjnn/wincode/blob/09f2d13ac87399b9b50d45c1600cf852b4b6bf58/apps/cli/src/modules/tool-gate/tool-gate.ts#L395-L460), [dispatch](https://github.com/sonwjnn/wincode/blob/09f2d13ac87399b9b50d45c1600cf852b4b6bf58/apps/cli/src/modules/conversations/hooks/tool-dispatch.ts#L225-L236))

## Uncertainties and limits

- OpenCode's `tool.execute.before` plugin hook can alter arguments; this note describes maintained built-ins/default behavior. ([hook](https://github.com/anomalyco/opencode/blob/03bba464d46f3eddf74195919b1344aa937f7b11/packages/opencode/src/session/tools.ts#L88-L111))
- Pi SDK embeddings may inject remote filesystem operations; this note describes the default CLI backend. ([contract](https://github.com/earendil-works/pi/blob/a470b121bf683b4c2b9fc0b3a7c807de7e0cfe9c/packages/coding-agent/src/core/tools/read.ts#L52-L76))
- No runtime experiment was performed because the assignment explicitly requested source/docs research and asked to skip validation commands. These are pinned-source findings, not claims about older releases or third-party forks.
