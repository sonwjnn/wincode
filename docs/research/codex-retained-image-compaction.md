# OpenAI Codex retained-image budgeting during remote compaction — research note

| | |
|---|---|

| Scope | `compact_remote_v2` retained-message budgeting, the `compaction_image_budget` rollout, and the limits of what the change establishes |

## Timeline and rollout

- **2026-08-23 — PR #40280 / commit `6677fd827d2c34cd65edb240418f80b3f97d2cc0`.** The PR and commit describe the original defect: remote compaction's retained-message budget counted text but not images, so image-heavy history could exceed the represented budget. The change introduced `compaction_image_budget` as an **opt-in** feature, using the existing image-size estimate, and added coverage for image boundaries, annotations, audio, text-only messages, client-authored developer messages, and repeated remote compaction. ([PR #40280](https://github.com/openai/codex/pull/40280), [commit `6677fd8`](https://github.com/openai/codex/commit/6677fd827d2c34cd65edb240418f80b3f97d2cc0))
- **2026-08-26 — PR #40994 / commit `528fd7ace5ec0a1c2a387dcb9c76a09f3fa011ee`.** The flag was promoted to `Stage::Stable` and `default_enabled: true`; the integration expectations changed so the default case trims images, while an explicit `false` preserves the previous behavior. ([PR #40994](https://github.com/openai/codex/pull/40994), [commit `528fd7a`](https://github.com/openai/codex/commit/528fd7ace5ec0a1c2a387dcb9c76a09f3fa011ee))
- **2026-08-27 — `rust-v0.150.1`.** The release was published at `2026-08-27T01:56:54Z`; its release notes say that remote compaction now counts retained images toward its token budget **by default** and trims older images as needed, with #41003 identified as the 0.150 backport. ([release page](https://github.com/openai/codex/releases/tag/rust-v0.150.1), [release metadata](https://api.github.com/repos/openai/codex/releases/tags/rust-v0.150.1), [backport PR #41003](https://github.com/openai/codex/pull/41003))

## What the fix does

The original implementation routes the feature state into the remote-v2 history builder. With the flag enabled, ordinary retained message content is charged using `message_content_token_count`; with it disabled, the compatibility wrapper uses the prior text-only path. Client-authored developer messages are deliberately excluded from image charging and retain their existing serialized-estimate boundary correction. ([initial implementation](https://github.com/openai/codex/blob/6677fd827d2c34cd65edb240418f80b3f97d2cc0/codex-rs/core/src/compact_remote_v2.rs#L597-L617), [current gate and builder](https://github.com/openai/codex/blob/379d50be35d393631f45fde69197f3b9a592aa02/codex-rs/core/src/compact_remote_v2.rs#L306-L322), [current truncation logic](https://github.com/openai/codex/blob/379d50be35d393631f45fde69197f3b9a592aa02/codex-rs/core/src/compact_remote_v2.rs#L589-L679))

`content_item_token_count` keeps text on the existing approximate text-token count, converts an image's shared estimated byte cost to approximate tokens, and charges audio as zero. The shared estimator uses a fixed resized-image estimate of 7,373 bytes and a 4-bytes/token ceiling heuristic; `detail: "original"` instead uses a 32-pixel patch estimate (bounded by the existing original-image cap). This is a context-budget estimate, not a claim about exact provider billing. ([image token estimator](https://github.com/openai/codex/blob/379d50be35d393631f45fde69197f3b9a592aa02/codex-rs/core/src/compact_remote_v2_images.rs#L15-L25), [shared image estimator](https://github.com/openai/codex/blob/379d50be35d393631f45fde69197f3b9a592aa02/codex-rs/core/src/context_manager/history.rs#L648-L656), [original-detail estimator](https://github.com/openai/codex/blob/379d50be35d393631f45fde69197f3b9a592aa02/codex-rs/core/src/context_manager/history.rs#L752-L795))

When truncation reaches an image-containing boundary message, the helper retains later content while treating each image and its adjacent harness labels as one atomic unit. It recognizes the image close label and the immediately preceding local/general image-open label, charges the group as a whole, and drops the group when it does not fit. Audio remains preserved and uncharged; annotation metadata is sliced with the retained content. ([image-boundary helper](https://github.com/openai/codex/blob/379d50be35d393631f45fde69197f3b9a592aa02/codex-rs/core/src/compact_remote_v2_images.rs#L31-L77), [unit tests for atomic boundary and no backfill](https://github.com/openai/codex/blob/379d50be35d393631f45fde69197f3b9a592aa02/codex-rs/core/src/compact_remote_v2_image_budget_tests.rs#L42-L115))

If an image-containing boundary does not fit, the implementation sets the remaining budget to zero before attempting that boundary, so it does **not** backfill older messages into the leftover budget. The current unit test names and asserts this behavior directly. ([initial no-backfill change](https://github.com/openai/codex/blob/6677fd827d2c34cd65edb240418f80b3f97d2cc0/codex-rs/core/src/compact_remote_v2.rs#L628-L635), [current no-backfill branch](https://github.com/openai/codex/blob/379d50be35d393631f45fde69197f3b9a592aa02/codex-rs/core/src/compact_remote_v2.rs#L637-L645), [test](https://github.com/openai/codex/blob/379d50be35d393631f45fde69197f3b9a592aa02/codex-rs/core/src/compact_remote_v2_image_budget_tests.rs#L42-L62))

## Residual limits and non-claims

- **Remote compaction scope only.** The evidence establishes the budget in `compact_remote_v2`: the feature is read while building the replacement history for the remote compaction task. This note does not generalize the behavior to local/other compaction implementations. ([remote-v2 call site](https://github.com/openai/codex/blob/379d50be35d393631f45fde69197f3b9a592aa02/codex-rs/core/src/compact_remote_v2.rs#L306-L322), [replacement-history construction](https://github.com/openai/codex/blob/379d50be35d393631f45fde69197f3b9a592aa02/codex-rs/core/src/compact_remote_v2.rs#L488-L513))
- **Not historical rollout-file cleanup.** The reviewed change budgets and installs the retained prompt history for a compaction; the PR, commits, release notes, and current source do not claim to delete old media from already-written rollout files. Therefore this fix is not evidence that historical rollout media was removed or repaired. ([history installation](https://github.com/openai/codex/blob/379d50be35d393631f45fde69197f3b9a592aa02/codex-rs/core/src/compact_remote_v2.rs#L323-L363), [PR #40280 scope](https://github.com/openai/codex/pull/40280), [release note](https://github.com/openai/codex/releases/tag/rust-v0.150.1))
- **Not a subscription quota reset.** None of the cited Codex implementation or release sources describes account/subscription quota accounting or a reset; this note makes no quota-reset claim. ([PR #40280](https://github.com/openai/codex/pull/40280), [PR #40994](https://github.com/openai/codex/pull/40994), [release `rust-v0.150.1`](https://github.com/openai/codex/releases/tag/rust-v0.150.1))
- **Compatibility boundaries remain.** The image path preserves text-only boundary behavior, preserves client-authored developer-message behavior, and leaves audio uncharged; the dedicated tests cover those cases. ([compatibility tests](https://github.com/openai/codex/blob/379d50be35d393631f45fde69197f3b9a592aa02/codex-rs/core/src/compact_remote_v2_image_budget_tests.rs#L117-L162), [image helper](https://github.com/openai/codex/blob/379d50be35d393631f45fde69197f3b9a592aa02/codex-rs/core/src/compact_remote_v2_images.rs#L31-L77))
